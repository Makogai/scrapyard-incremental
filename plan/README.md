# Scrapyard Incremental Plan

This folder is the authoritative product and delivery plan. The older `docs/` folder describes Merge a Snowman and is legacy until replaced during Phase 0.

## Reading Order

1. `MEMORY.md` - current state and next action
2. `GAME_DESIGN.md` - player experience and MVP boundaries
3. `ARCHITECTURE.md` - modules, ownership, and data flow
4. `ECONOMY.md` - progression targets and formulas
5. `WORLD_AND_STUDIO.md` - editable Studio map contract
6. `UI_UX.md` - mobile interface contract
7. `SECURITY_AND_TESTING.md` - trust model and verification
8. `ROADMAP.md` and `phases/*` - execution order and acceptance gates

## Planning Rule

A phase may start only when the previous phase's automated gate passes and its required manual Studio checks are either completed or explicitly recorded as outstanding. `MEMORY.md` is updated after every meaningful work session.
