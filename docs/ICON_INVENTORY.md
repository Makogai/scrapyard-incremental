## Base prompt

The shared style block lives in [ICON_PROMPTS.md](ICON_PROMPTS.md) and is reproduced
here as one line, ready to paste into an image tool. **Paste the style block, then one
subject line.** Never paraphrase the style block between generations — it is the only
thing keeping the set coherent.

> Cartoon game icon for a mobile game, single centred object on a fully transparent
> background. Chunky simplified shapes with a thick uniform dark outline in near-black
> (#10131A). Flat colour fills with one soft top-to-bottom gradient per shape and a
> single soft highlight; no textures, no noise, no gritty detail. Bold and readable at
> small size: one clear silhouette, big forms, no thin lines and no small text.
> Friendly, glossy, slightly toy-like, like a Roblox shop icon. Three-quarter front
> view, straight-on, object filling most of the frame with a small even margin.
> Vector-clean edges, no drop shadow, no ground shadow, no background panel, no frame,
> no border. Square 1024x1024, transparent background.

**Negative prompt**, if the tool takes one:

> photorealistic, realistic, 3D render, ray tracing, gritty, rusty texture, noise,
> grain, sketch, painterly brush strokes, thin outlines, fine detail, text, letters,
> numbers, watermark, logo, drop shadow, background, panel, border, frame, multiple
> objects, cluttered composition, dull desaturated colours

### Pets and eggs

Each pet needs its own subject line written from its name and rarity — a Secret pet
should read louder than a Common one. Keep silhouettes distinct: the risk with 21 pets
is that half of them converge on "round thing with eyes". Push shape language apart
(horns, wings, crowns, shells) rather than relying on colour.

Eggs share a shape, so separate them by shell treatment and palette, matching the area
they belong to: Front Yard (grassy/scrap), Workshop (metal/bolts), Vehicle Graveyard
(rusted/chrome).

## Specs

- **1024×1024, square, transparent PNG.** Never wide — every icon box is square and a
  wide image gets letterboxed.
- **No baked-in text.** Cards and rows draw their own labels; card titles render their
  lead token oversized, so art containing "2X" fights it.
- **No background panel, frame or drop shadow.** Every slot supplies its own well,
  gradient, outline and corner radius.
- **Check at 128 px before uploading** — roughly what a card's art well renders at on
  desktop, smaller on phone.
- **Name the file exactly what the slot is called.** Roblox's uploader takes the asset
  name straight from the filename, and our catalog is keyed on it.

## How to actually generate these

Learned the hard way on 2026-08-25. Follow this recipe rather than the prose
style block alone — the style block by itself is not enough.

**1. Give it reference images, not just words.** Text-only prompts produce
over-rendered, heavily shaded results that do not sit next to the pack. Attaching
three existing pack icons (`Trophi.png`, `Star.png`, `Check.png` / `Bolt.png`) and
saying *"copy their art style EXACTLY"* fixes it in one shot. Keep the same three
references for a whole batch so the batch stays coherent.

**2. Generate four at a time as a 2x2 sheet.** One icon per request costs about
4 minutes; a 2x2 sheet costs about 5 minutes for four. Ask for *"4 separate icons
in a clean 2x2 grid, evenly spaced with clear empty gaps so no two icons touch,
fully transparent background"* and name each quadrant.

**3. Check transparency before paying for a background pass.** Single-icon
generations came back with a **black** background and needed a separate "Remove
BG" round-trip (another ~2 minutes). The 2x2 sheet came back genuinely
transparent. ChatGPT's viewer renders transparency as black either way, so the
viewer lies — download it and check the alpha:

```
python -c "from PIL import Image; print(Image.open('sheet.png').convert('RGBA').getpixel((3,3)))"
```

Alpha `0` means it is already transparent and no BG pass is needed.

**4. Normalise locally, always.** Generations come back at arbitrary sizes
(1254x1254 for a sheet, 1241x1268 after a BG pass) and never at spec. Two scripts
in `D:\code\Roblox\RobloxAssets\build\` do this:

```
python split_sheet.py <sheet.png> 2 2 <outdir> plus minus clock sign
python normalize.py <single.png> <out.png>
```

Both trim to the alpha bounding box, centre on a square transparent canvas with an
even margin, and output exactly 1024x1024 RGBA. Trimming by alpha is what makes
the grid split forgiving — the generator only has to keep each icon inside its own
cell, not place it precisely.

**5. Expect the ChatGPT UI to fight you.** Observed repeatedly: the send button
stays disabled while a previous response is still finalising; clicking by
coordinate misses because the composer grows as you type; and long sessions can
wedge the tab entirely. Clear the composer with ctrl+a before reusing it, and
reload the conversation if the send arrow will not light up.
